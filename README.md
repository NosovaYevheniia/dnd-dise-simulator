# dnd-dise-simulator-and-setup

## What this project is about:
This application is about a possibility of easy online dice rolling and dnd game setup. The application uses a random number generator to mimic rolling physical dices and allows to make a full game setup. Its created to make a dnd session easier and more enjoyable, even without a full gameset. Its suitable for seasoned players and beginners alike. It supports customization of the dices, in order to be suitable for all kinds of games. This project is for young, creative, social people and adults with all kinds of backgrounds, who want to enjoy the game without additional spendings.

## What this project needs:
- Easy, simple interface. 
- Its made for quick use, and shouldn't take a lot of time to make a dice roll. 
- Should contain all kinds of details and conventions of a specific dnd session. 
- Dice customiation options: from the color to  the way the numbers on the dices look
- The ability to setup the game, see the map/enemies
